# 🏏 IPL Analytics Dashboard | Power BI

## 📌 Project Overview

This project presents a comprehensive IPL Analytics Dashboard developed in Power BI using IPL ball-by-ball data from 2008 to 2026. The dashboard provides interactive insights into player performance, team achievements, scoring trends, venue statistics, and match outcomes through visually appealing and data-driven reports.

The objective of this project is to transform raw cricket data into actionable insights using data modeling, DAX calculations, and interactive visualizations.

---

## 🎯 Key Features

### 🟠 Orange Cap Analysis

* Season-wise Orange Cap Winners
* Total runs scored by the leading batter

### 🟣 Purple Cap Analysis

* Season-wise Purple Cap Winners
* Total wickets taken by the leading bowler

### 🏆 IPL Champions

* Season-wise IPL Champions
* Historical championship tracking

### ⭐ Player Performance

* Most Player of the Match awards
* Most Sixes in a season
* Top Run Scorers in IPL history
* Top Wicket Takers in IPL history

### 📈 Trend Analysis

* Runs Trend Across IPL Seasons
* Team Wins Analysis
* Toss Decision Analysis

### 🏟 Venue & Geographic Analysis

* Venue-wise Match Distribution
* City-wise Match Analysis
* Match Hosting Insights

## 📂 Dataset Information

The dataset contains ball-by-ball IPL match data covering multiple seasons from 2008 to 2026, including:

* Match Information
* Player Statistics
* Batting Performance
* Bowling Performance
* Team Results
* Venue Details
* Toss Decisions

**Note:** The 2026 IPL season data is partial and includes only the matches available at the time of dataset collection. Therefore, statistics and insights for 2026 may change as additional matches are played.

---

## 📈 Key Insights

* Identified the highest run scorers and wicket takers in IPL history.
* Analyzed long-term scoring trends across IPL seasons.
* Evaluated team dominance based on match victories.
* Explored venue-specific match distributions.
* Compared batting and bowling achievements season-wise.
